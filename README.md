# 🎨 Monet Digital Gallery 

**[✨ View Live Site Here ✨](https://skhnzss.github.io/monetbysh/)**

## About the Project
A curated digital gallery dedicated to the life and art of French Impressionist Claude Monet. Designed with a strict focus on typography, soft Monet's aesthetics, and an immersive user experience. 

This project serves as a seamless intersection of art history and modern web development. 

**Inspiration:** The educational depth and aesthetic vision of this project were deeply inspired by the art history programs at **Art Explora Academy (Sorbonne Université)**.

## Features
* **Elegant UI/UX:** Minimalist design, carefully selected typography, and a cohesive pastel color palette.
* **Interactive Guestbook:** Real-time comment section where visitors can share their impressions, powered by Google Firebase.

## Technologies Used
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend/Database:** Firebase (Firestore)
* **Prototyping & Design:** Figma
